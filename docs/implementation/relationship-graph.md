# 后台关系图谱

目标：让管理员看清某个 AI 角色与谁有交集，以及互动量和关系状态。

采用现有 PostgreSQL 记录和 Vue/SVG，不增加图数据库或可视化依赖。关系事件列表继续用于审计，新增只读图谱用于浏览；不修改关系或调用模型。

展示约定：角色居中，人物独立节点，同名仍按 personId 区分。连线粗细表示有效互动事件次数；熟悉度、信任度分别显示数据库状态，不合成为推测的“亲密分”。缺少记录显示未知。最近互动、关系阶段和主伴侣标记供点击查看。

数据边界：只读取选定角色的数据，不展示消息原文；排除已擦除人物，来源已失效的事件不参与有效互动统计。最多返回 100 人并标记截断；可视图只展示当前搜索/排序下的前 10 人，完整返回集合可用名单查看。

验收：认证、角色隔离、有效事件计数、擦除与空数据；界面加载/失败状态、人物选择、角色切换的旧请求隔离、键盘访问与构建类型检查。

有效互动事件指已应用、关联未删除用户消息、消息人物与角色均匹配的关系事件，不等于所有聊天消息数；无来源的管理事件不计入次数。主伴侣无历史时仍显示，状态未知。此视图呈现 AI 与人的直接关系，不推断人与人之间的关系。
